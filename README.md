# Colheita Programada

## Sobre o Projeto

Colheita Programada é um protótipo de jogo sério baseado em programação visual, desenvolvido com o objetivo de apoiar o ensino de conceitos introdutórios de lógica de programação. O projeto incorpora mecânicas de automação e feedback multimodal, além de um sistema de tradução entre programação visual e textual como recurso de apoio à aprendizagem.

O desenvolvimento do protótipo fundamenta-se em uma revisão da literatura voltada à identificação dos principais desafios enfrentados por estudantes no processo de aprendizagem introdutória de lógica de programação, buscando contribuir para a investigação de estratégias educacionais iterativas nessa área.

## Sobre a Pesquisa

Este projeto foi desenvolvido no âmbito de uma pesquisa, propõe mecânicas de jogo voltadas ao ensino de lógica de programação. 
O protótipo e seus materiais foram disponibilizados publicamente com o intuito de favorecer a transparência, o rigor e a reprodutibilidade da pesquisa.
